# AyesayRent V2

## Project

AyesayRent V2 is a property rental management platform for the Myanmar community living in Bangkok.

The system has two parts:

1. Admin Panel

2. Public Website

The admin panel is used to manage apartments, room rates, amenities, fees, nearby places, photos, and availability requests.

The public website allows customers to search apartments by area, BTS/MRT, monthly rent, and other filters.

---

## Technology Stack

- Next.js App Router

- TypeScript

- Tailwind CSS

- Supabase

- Vercel

---

## Development Principles

- Build one Feature Pack at a time.

- Never break working features.

- Never guess the database schema.

- Always inspect existing code before modifying it.

- Prefer reusable components.

- Keep files organized by feature.

- Complete one module before starting another.
